# alō by Saratoga — landing page (IT / EN / FR)

Sito statico pronto per GitHub Pages.

- `/` italiano · `/en/` inglese · `/fr/` francese
- `assets/` video di sfondo, video di lancio nelle 3 lingue, foto, logo
- Modulo demo: apre un'email precompilata verso l'indirizzo in `const TO` (in fondo a ogni `index.html`)

## Pubblicazione
1. Crea un repository pubblico (es. `alo`) sull'account GitHub Saratoga
2. Carica il contenuto di questa cartella nella root del branch `main`
3. Settings → Pages → Deploy from a branch → `main` / root
